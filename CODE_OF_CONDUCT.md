# Code of conduct

This is a small project about doing chores with agents. Keep the issues, pull requests and
discussions about that, and treat the people in them with respect.

## Expected

- Be patient with beginners. The book is written for people who are new to agents, and a question
  that looks basic is the kind of question the book is for.
- Criticize code, text, and decisions, not people.
- Assume good intent, and ask when something is unclear.

## Not acceptable

- Harassment, insults, or personal attacks of any kind.
- Posting anyone's personal information, including your own. This project is about keeping personal
  data out of public places; that applies to its issues too. Describe a file ("a PDF from my bank"),
  do not name it.
- Spam, advertising, or sustained off-topic posting.

## What happens

The maintainer may edit or delete comments, close issues and pull requests, or block an account
that does not follow this code. Personal information posted by mistake will be removed as soon as
it is noticed, and you can ask for that yourself.

To report a problem privately, use the repository's **Security** tab and choose **Report a
vulnerability**. It reaches only the maintainer, and it works for conduct reports as well as
security ones.
